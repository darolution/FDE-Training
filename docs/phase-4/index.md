# Phase 4 · Architecture and delivery

**Weeks 17–22 · not yet written.**

**Capstone 4: Harbourview Health policy assistant.** Harbourview (fictional) is a hospital network. Staff ask questions about clinical and HR policies, and answers must cite the source and respect who's allowed to see what. Deliverables: a running service, an architecture decision record, a data-flow and privacy assessment, a cost model, and an executive readout.

| Week | Topic | Key outcomes |
|---|---|---|
| 17 | Enterprise deployment | Claude API vs Amazon Bedrock vs Google Vertex AI vs Microsoft Foundry: identity, networking, data retention, regions, quotas |
| 18 | Regulated industries | Privacy and data residency, financial- and health-sector rules, model risk management, audit evidence. Worked examples from Canada (PIPEDA, PHIPA, OSFI), the US and the EU. **Verify each source's current status when you get here** |
| 19 | Cost, latency and capacity | Model routing, caching strategy, batching, rate limits, and a cost model a CFO will accept |
| 20 | Shipping | FastAPI service, Docker, CI with evals as a gate, a human-review UI |
| 21 | Customer skills | Discovery interviews, success metrics, scoping and saying no, demos, change management, writing for executives |
| 22 | Capstone 4 | The full engagement, with an architecture review |
