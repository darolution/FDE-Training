# Phase 5 · Residency simulation

**Weeks 23–24 · not yet written.**

## Week 23: the four-day intensive, simulated

Modelled on the public description of the FDE Residency's intensive (see [The FDE role](../reference/fde-role.md)). A deck of sealed scenario cards from industries you haven't practised (logistics, public sector, legal, manufacturing, banking operations). Draw one and you're on the clock:

| Day | You deliver |
|---|---|
| 1 | Discovery questions and answers (role-played from the card), a one-page design, acceptance criteria |
| 2–3 | A working system with an eval that passes |
| 4 | Security review, handover doc, a 10-minute demo, and a self-assessment against the criteria |

## Week 24: portfolio and interview prep

- Polish four capstones: README, architecture diagram, eval results, a demo video
- Two public write-ups (for example: evals for a claims workflow; red-teaming a support agent)
- Mock loops: technical use-case screen, solution design for a regulated customer, a practical coding exercise, values and "why this work"
