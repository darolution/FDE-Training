# The FDE role

*Sources checked 2026-10-06. Programs and job postings change, so re-check before you rely on any detail.*

## What a Forward Deployed Engineer does

Anthropic's FDE postings (Applied AI team) describe the job as embedding with strategic customers to build production applications on Claude. In summary:

- Build production applications **inside customer systems**: agents, MCP servers, sub-agents, skills
- Give hands-on deployment support in enterprise environments
- Spot repeatable deployment patterns and feed them back to product and engineering
- Travel to customer sites regularly

The postings ask for **about 3–4+ years in a technical, customer-facing role** (an FDE, a software engineer with consulting experience, or a technical founder), strong Python and LLM skills, and comfort with ambiguity. The interview loop reported by candidates mixes a Claude use-case screen, a practical coding exercise, a solution-design round for an enterprise customer (security and compliance come up), and a values interview.

## Claude Frontier Academy and the FDE Residency

Anthropic announced **Claude Frontier Academy**: $100M to train 10,000 engineers by the end of 2027, with first credentials expected in early 2027. Its first program is the **FDE Residency**:

- **Intensive (4 days):** build a Claude system for a simulated enterprise scenario "from the first customer request through security review to handover", then get assessed on a new scenario → *Claude Resident Engineer* badge.
- **Residency (12 weeks):** lead a real Claude deployment at your own organisation with cohort mentorship and support from Anthropic engineers → practical assessment → *Claude Frontier Deployed Engineer* badge.
- **Access:** early access through select customers and partners. Interest is registered through an Anthropic account team or partner manager.

This course mirrors that structure: every capstone runs request → build → evals → security review → handover, and [Phase 5](../phase-5/index.md) simulates the intensive.

## How this course maps to the job

| The job asks for | Where you practise it |
|---|---|
| Ship production Claude apps | Every capstone |
| Agents, MCP servers, skills, sub-agents | Weeks 5, 6, 11–14 |
| Security and compliance in solution design | Week 9, Week 18, every security review |
| Customer-facing judgment | Discovery and handover in every capstone, Week 21 |
| Codify patterns | Your write-ups and `docs/notes/` |
