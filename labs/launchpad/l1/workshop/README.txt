Welcome to the workshop.

A secret phrase is hidden in this folder, split into three parts.
Each part is in a file somewhere below this folder. Use only the terminal:

  - list what's in a folder      (Windows: dir    macOS/Linux: ls)
  - move into a folder           (cd foldername)
  - go back up one level         (cd ..)
  - print a file's contents      (Windows: type file.txt    macOS/Linux: cat file.txt)

Join the three parts with dashes, in order (part 1, part 2, part 3).
Write the phrase into a new file called answers.txt in the l1 folder
(one level up from this workshop folder), then run the checker:

  python labs/launchpad/l1/check_l1.py
